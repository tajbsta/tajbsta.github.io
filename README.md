# Taj Bist — GitHub Pages Portfolio

A responsive, dependency-free portfolio based on the supplied LinkedIn profile. Graduate education is described as studies rather than asserting degree completion. No employer accomplishments or technical proficiencies have been invented.

## Publish at https://tajbsta.github.io
1. Create a GitHub repository named `tajbsta.github.io` under the `tajbsta` account.
2. Upload `index.html` and `.nojekyll` to the repository root on `main`.
3. In Settings → Pages, select Deploy from a branch, `main`, `/ (root)`, and Save.
4. Wait for the Pages deployment to finish. GitHub Pages publishing will make this portfolio publicly accessible.

## Customize
Edit the text and links directly in index.html. Add verified project links, work accomplishments, and a contact email when available. All styles are embedded. No dependencies, API keys, analytics, or third-party assets are required.
